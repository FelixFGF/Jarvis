CAPABILITIES

More than a chat box.

Jarvis brings AI conversations and practical desktop actions into one place. What’s available depends on your model, services, permissions, and installed apps.

01 / THINK

Chat with your chosen model

Connect a local model server such as Ollama, LM Studio, or BionicGPT, or use a compatible external API. Load available models, choose the one you want, and chat with it from the Windows desktop.

Local model serverOllama · LM Studio
Compatible APIOptional cloud
The model provider is configured by you — it is not Jarvis itself.
02 / ACT

Useful desktop tools

Search the web (Google first, with clearly identified fallbacks), find files in folders you approve, open supported apps and games, and list, move, maximize, or close windows. Tool calls and their results are shown in chat; actions that need permission ask in the conversation.

Web searchApps & gamesFiles & windows
03 / PLAN

Tasks with visible steps

For supported requests, Jarvis can show a step-by-step checklist and tool progress so you can see what it is attempting — not just read a final answer.

04 / SPEAK

A more natural conversation

Dictate with downloadable Whisper model choices that run locally after setup. Dictation places editable text in the prompt; it never sends it automatically. Voice mode supports spoken turn-by-turn conversation, with local Piper neural voices or Windows voices for replies.

Local Whisper · Piper and Windows voices
05 / LISTEN

Your music, within reach

Connect Spotify in Settings to search for and play tracks, like songs, manage playlists, and adjust Spotify’s own Windows audio-session volume. Some playback actions require Spotify Premium and an active player. Apple Music can search its catalog, open tracks externally, and—with Apple tokens—add tracks to the library or playlists. External Apple Music playback cannot be verified by Jarvis.

GOOD TO KNOW

Questions, answered.

A few details to help you understand what Jarvis can — and cannot — do today.

Is Jarvis itself an AI model?＋

No. Jarvis is the Windows application. It connects to whichever compatible AI model or endpoint you configure, and the selected model's capabilities affect what it can do.

Does Jarvis work completely offline?＋

Some workflows can use local models and local speech tools. Web search, cloud endpoints, Spotify and other connected services need the relevant network access and, where required, authorization.

Can Jarvis control every app on my PC?＋

No. Supported tools can search for and launch installed apps and games, work with windows, and access approved folders. The availability and reliability of an action depend on its integration and your environment.

Does it support Discord voice, camera or screen sharing?＋

Not yet. Full Discord control for voice channels, microphone, camera and screen sharing has not been integrated.

Are Spotify and Apple Music supported?＋

Spotify supports track search and playback, likes, playlists, and app-session volume when connected; some actions require Premium or an active player. Apple Music supports catalog search, external track opening, and token-authorized library and playlist actions. Playback opened externally cannot be verified.

Why might a tool not work with my chosen model?＋

Some tools depend on the model supporting tool calling, the server exposing compatible behavior, and the required permissions and services being available.

Can Jarvis generate images? ＋

Image generation is not included in the current Windows app.

Where do I get the installer?＋

Use the Download for Windows button. The Download buttons open the latest Windows installer directly from GitHub Releases. A background request records the click for the private statistics dashboard.

Does the website count download clicks?＋

Yes. A background request records the timestamp and the version label shown by the website for usage statistics while the download button opens GitHub directly. The event records do not store your IP address, and a recorded click does not prove that the installer finished downloading or was installed. Netlify may process technical request data as part of hosting and security operations.
